# CR2 需求｜数据与授权

**阶段：**phase-1／原任务 3。**目的：**在目标 WorkBuddy 上把公开与机构数据的安装、权限、真实取数、来源口径、回退及本机重装跑通；把任何不可用的数据域显式隔离，防止空结果、无权限或公开数据被包装成完整机构研报。本 CR 不验收研究内容或文件交付。

## 进入条件与依据

接收 [CR1《基线与专家包》](2026-09-26-workbuddy-equity-research-cr1-baseline-package.md) **已经验收的**导出包、目标机安装与九项路由记录、九项等价映射、固定样例及 `ACCEPTANCE.md` 模板；特别检查 `agents/equity-research.md` 已载明七个数据域的首选/降级顺序。这里只把包的可安装和路由当作已知前提，**不把连接器声明、旧机“曾连接一次”或样例选择当作真实取数已通过**。

## 范围

1. **安装、授权和使用边界。**在目标 WorkBuddy 版本分别核对 `wind-finance`、`tdx-connector`、`neodata` 机构入口，以及公开面 `finance-data` 中的 `westock-data`、`westock-tool`、`neodata-financial-search`；核对 westock CLI 本机安装、neodata 云服务连接和 `.codebuddy-plugin/plugin.json` 的 `dependencies.connectors` 标识是否被目标机识别。登记每个数据源的安装步骤、服务/版本、所需账号权限、许可范围（本机自用、研究引用/展示、文件中的数据是否允许使用）、密钥存储位置的**说明而非密钥**。任何不确定的商业许可先标待确认，不自行扩大权限；不能因为插件可见就视为获准。
2. **真实取数与溯源。**在已授权账户上，用 CR1 固定财报样例及必要的 A股/港股样例，在行情、公告/财务、券商一致预期、研报评级/目标价、筛选、宏观、资金等适用数据域，执行真实查询，留存测试日期、查询条件、证券代码/交易所、财报期间、返回字段、原始链接或文件及时间戳、来源和口径。以 CR1 Agent 的七域顺序为核对清单；同一任务同一指标单源，不拼接异口径序列，不把 `neodata` 盈利预测未审查地称为同口径券商共识。无等价来源的域写“不支持/仅公开摘要”，不要发明补位指标。
3. **降级和停止规则。**实测订阅缺失、权限拒绝、断网、空结果、过期数据、冲突来源、错误证券代码、指定历史季度以及美股个股请求。过期时告知截至日期，错误代码先澄清；历史季度按指定期间取，不偷偷改为最新；冲突标明各自来源和日期并停止不可靠结论。授权不足先试有使用权、**同口径且满足任务质量**的备选，否则只给带缺口/时效/来源说明的“公开数据摘要”，或停在缺失步骤；不得照常输出评级、目标价、估值或完整报告。美股个股仅使用公开面并显式说明不接入美系机构数据源。所有回退记录触发原因、所用源和与原需求的差异。
4. **本机重装。**从仓库源重新导出，经目标机认可的校验/注册路径卸下或隔离旧包后安装；新开会话、只保留包声明的依赖，在同一台机器逐一连接并实际调用必需工具，核对九项路由、已授权数据源的真实查询及缺权限的负例仍有效。识别开发机全局配置、缓存、私有绝对路径和旧凭据依赖；需要本机账户重新授权的，文档化授权步骤与结果。不得把默认运行时目录 `~/.workbuddy/plugins/marketplaces/my-experts/plugins` 当源代码目录或公开市场证明。

## 交付物

- 数据源接入与许可台账：逐源安装/授权路径、许可范围和待确认点；只记权限状态，不含密钥、客户数据或内网凭据。
- 按数据域的真实查询证据、字段/时间/口径/来源记录与能力状态表：**可用、可降级但质量受限、阻塞**，以及适用的九项任务。
- 正例、反例及降级记录；本机重新导出、校验、安装、取数的可复现步骤及版本记录。必要时同步修正 Agent 静态路由和专家包声明，并重导出/重跑受影响的路由验收。

## 验收标准

- 所有被标为“可用”的**任务必需数据域**，均在目标机用合法授权完成真实请求并保留可复核证据；首次源失败时验证允许的备选是否可用。仅返回演示数据、命中旧缓存、看到连接器名称或测试脚本存在，不算真实取数。对无许可/无匹配源的域标阻塞，不签成完整版能力。
- 对无权限、断网、空结果、过期、历史季度、错误代码和相互矛盾来源均有可复现的停止/降级行为；实际回复不含无来源数字及未经数据支持的评级/目标价。公开摘要必须直说覆盖和时效；美股公开面必须标注机构数据限制。
- 同一指标的最终采用源及跨源差异可追溯；许可范围没有被包内样例、附件或导出流程越过；包无真实凭据。重装后路由和已获授权的取数仍可复现，失败时说明可重授权路径。
- 服务清单逐个记录实际需要的只读/写入工具和动作、许可主体及用户侧授权方式；台账明确区分**已验证数据域**与**尚不能支持完整版的任务**。只把已获准且实取通过的必需数据域交给下游；如缺 M1 必需财务/一致预期/旧模型关联数据等且无合格替代，CR3 的对应验收必须阻塞，而非以本 CR 的安全降级测试顶替。其余六项同理，不能凭“CR2 通过”默认所有数据齐备。

## 不包含／交接条件

不包含九项报告与模型的研究质量判定、研究结论人工审核、非开发者第二用户安装、公开分发的再许可批准或市场审核。向 CR3 交接的是**已验收的具体数据域＋真实取数/授权证据＋安全降级记录**，不是泛称“数据已接入”；向 CR4 同样按各项所需数据域交接。许可不能确认或必需查询未成功时保留阻塞状态，允许继续准备不依赖该域的工作，但不签相关任务为通过。
