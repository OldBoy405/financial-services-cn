# CR3 需求｜研究主链 M1

**阶段：**phase-1／原任务 4 前半。**目的：**让 `earnings`、`initiate`、`model-update` 三项在真实 A股/港股研究任务中可用，产出可下载、可打开、可溯源的文件，并验证多轮及退出后重新进入会话的接续。M1 是内部中间里程碑，**不是九项功能完成**。

## 进入条件：必须是已验收的产物/能力

- [CR1《基线与专家包》](2026-09-26-workbuddy-equity-research-cr1-baseline-package.md)：可从源重建、在目标 WorkBuddy 本机实际安装并正确路由的单 Agent 专家包；九项等价映射表中这三项的旧命令额外要求、固定财报样例和 `ACCEPTANCE.md` 记录位已验收。不能拿“技能副本在包内”替代实际路由。
- [CR2《数据与授权》](2026-09-26-workbuddy-equity-research-cr2-data-authorization.md)：三项**必需**财务/公告、历史期间、获许可的研报/一致预期（适用时）、公开行情等数据域，在目标机已有真实取数、权限及来源口径证据；备选与阻塞边界已实测。本机重装后的授权路径已确认。某域只能给公开摘要时，对应完整版任务不得宣称通过。
- 准备一份有合法使用权的既有 Excel 模型，记录其公式/引用/假设和基线快照；不能用空表的“新建模型”替代既有模型更新验收。

## 范围与交付

1. **`earnings`：真实季报点评。**以已确定的样例财报和指定季度请求执行，核对期间、公告及 transcript 日期、发布后三个月时效规则、券商一致预期来源或缺口、beat/miss 逐项量化的可比口径、关键数字的来源/单位/时效、表格、图表、引文和工作底稿。按九项等价映射表逐条对照旧 `commands/earnings.md` 的质量清单，不仅对照 `earnings-analysis` 技能正文。产物为全中文（图表标签亦中文）、约 8–12 页的 DOCX 与可核对的 Summary，中文命名如 `[公司]_[年]Q[季]_季报点评.docx`；A股买入/增持/中性/减持/卖出五档与 CNY 目标价只在数据与人工审阅条件充分时出现，否则标明缺口、不编造。原命令的图表数及英文篇幅等要求须按 CR1 映射后的中文质量口径核对，有未等价条目则记录偏差并由用户裁决。若只具备公开面数据，成果只能标“公开数据摘要”试点，不能签为完整版 `earnings`。
2. **`model-update`：更新既有模型。**在保留原文件副本前提下修改既有 Excel 模型的已核实财务/预测假设，输出更新后 XLSX 与变更记录（单元格、前后值、假设和出处）。打开文件检查活公式可计算、引用不断链、关键假设和相关工作表仍存在，必要时做重算/抽样对账；静态数字表或新建空模型不算替代。
3. **`initiate`：五阶段多轮研究。**由用户**分别发起五次请求**，每步交付并等待确认后才继续：研究文档、Excel 模型、估值分析文档并更新模型、图表 ZIP、最终 DOCX；记录每步输入、追问、来源及产物的文件路径/标识；中途退出并重新进入会话，提供先前产物继续。Task 3 缺 Task 2、Task 5 缺图表 ZIP 等前置文件时必须停止并指出所缺产物，不生成占位估值或报告。完成后下载、打开并核对每类文件实际内容；只在所有阶段及文件均通过时签该技能通过。
4. **文件路由与可复核性。**文档/表格/演示类请求先经 `tencent-docs-routing`，并按内置技能规定在编辑前查询 schema、对既有表格委派 sheet-agent；使用目标 WorkBuddy 版本实测可用的原生能力：DOCX 优先 `tencent-docx`（研报体量使用其 `stock-research-report-expert` 路径）；新建 XLSX 用 `tencent-docs-sheet-generation` 并校验公式/重算；既有模型用 `tencent-docs-sheetagent`，不得覆盖公式区为静态表；本机文件打开核对用 `tencent-local-office-edit`/宿主预览；图表 ZIP 无对应内置技能时用最小 matplotlib 脚本并记录脚本、输入来源与依赖。上述是**预期工具路由，不是端到端能力已通过的证据**；目标版本不支持时以实测缺口和最小替代方案记录，重做对应验收。
5. **负例与边界。**对三项至少覆盖各自的 CN/EN 实际问法、指定历史季度、代码歧义或错误、空结果/无权限、冲突来源、缺共识和缺前置文件；至少一次美股个股请求只允许公开面，须明确标注不接入美系机构数据源。没有适用的负例在模板中说明原因和相邻验证路径，不能无记录跳过。来源/许可不足时停止或降为公开摘要，不把缺失数据补成目标价、评级或完整文件。

## 交付物

- 三项各自的真实研究请求、数据与引用证据、产物文件（DOCX、既有模型修改后的 XLSX，以及 `initiate` 各阶段实际要求的中间文件与图表 ZIP）、下载后打开核验记录和跨会话重入记录。
- 对照旧命令/技能的逐项验收记录，含未满足的等价项、负例实际回复、审阅意见；将每项证据与状态填入 `workbuddy-experts/equity-research/ACCEPTANCE.md`，附用户裁决。必要的技能改动保留源→导出副本一致并更新包版本，重测受影响的路由/数据用例。

## 验收标准

- `earnings`：指定季度准确，关键表/图/引文均有可复核来源与时效；DOCX 下载、打开、中文呈现和页数锚符合映射后的口径；不支持的共识/评级/目标价不会凭空出现。仅摘要模式不算完整版通过。
- `model-update`：更新前后差异可解释，重开 XLSX 后活公式、引用和假设连续，关键输出可重算；不是静态数字快照。
- `initiate`：五阶段与跨会话接续在真实任务中完成，每步文件可恢复、可下载和可打开；故意缺 Task 2/图表时能正确停下；引用和财务假设能够溯源。
- 三项分别通过正例和适用负例，用户在 `ACCEPTANCE.md` 逐项裁决；若工具、授权或质量不满足，标不通过/待补而非签字。已验收的三项只可宣称 M1 可用（**3/9**），不得代替余下六项。

## 不包含／交接条件

不包含 `earnings-preview`、`morning-note`、`idea-generation`、`sector-overview`、`thesis-tracker`、`catalyst-calendar` 的功能验收，也不包含市场提交或第二用户复测。向 CR4 交接的是**仍有效的三份用户裁决记录及可打开的真实产物**；若 CR4 的修改影响 M1 文件工具、数据域或技能，须重测受影响项后才能计入最终 9/9。
